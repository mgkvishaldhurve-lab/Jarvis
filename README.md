# JARVIS AI — Version 1.0

A mobile-friendly Hindi-first AI assistant interface starter.

## Current status
This version is a **front-end preview**. It has a responsive chat layout and basic chat interactions, but it does not generate real AI answers yet.

## Run it
1. Download and extract this project.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new **Public** repository named `jarvis-ai`.
3. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.

## Next development step: connect a real AI model
A real AI connection requires a backend/server. Keep API keys on the server in environment variables. **Never paste an API key into `app.js`, `index.html`, or any public GitHub repository.**
